# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/b9765c0c-5760-4f17-904b-fa859cb33965

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. Open the app and add your own Gemini API key in **Settings** (top toolbar) - this project no longer reads a `GEMINI_API_KEY` from the server environment; every user supplies their own key from the UI.
